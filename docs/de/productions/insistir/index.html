Insistir

Szenische Performance für eine einzige Interpretin auf der Bühne, getragen von Nicola Beller Carbone und um Stücke von Georges Aperghis gebaut. Im Dialog mit einer Gründungsgeste — Susan Sontags Inszenierung von Warten auf Godot im belagerten Sarajevo (1993) — befragt sie die Präsenz in der Extremsituation: die Stimme als Material, die Wiederholung als Akt, das Beharren als Widerstand. Uraufführung geplant in Mexiko-Stadt 2026.
