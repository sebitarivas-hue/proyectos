input / body / output

Performance para directora sola, sensores, sonido espacializado y vídeo interactivo —subtitulada «Conducting the Invisible». El gesto de dirección de Rut Schreiner, captado en tiempo real, genera, modula y esculpe el sonido: el cuerpo se vuelve instrumento, la dirección de orquesta, materia musical.
