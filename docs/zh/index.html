02为何

舞台形式正经历深刻的转变。

STOPERA! 汇聚艺术家、研究者、机构与公众，围绕一个共同的问题：二十一世纪需要怎样的舞台形式？

06支持与合作

支持 STOPERA!

艺术家、艺术节、剧院、机构、赞助者：加入 STOPERA! 有多种方式，让明日的作品与项目成为可能。

  • 作为艺术家合作

    艺术家、表演者、作者、研究者：提交项目、合作或 LIPS 申请。

    提交项目 →

  • 成为伙伴

    艺术节、剧院、机构：在法国与国际间联合制作并巡演我们的作品。

    成为伙伴 →

  • 支持一部作品

    赞助者与捐助者：支持一部创作，从工作坊到舞台。

    支持 →

  • 成为会员

    加入 STOPERA! 网络，长期支持平台。
