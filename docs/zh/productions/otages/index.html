Otages

一部根据 Nina Bouraoui 文本创作的三幕歌剧。Sylvie Meyer 的肖像——一个「平凡而非凡」的女人，五十三年来顺从他人的期待，直到那个颠覆一切、既应受谴责又带来解放的举动：「我是 Sylvie Meyer」。Richard Brunel 执导。
